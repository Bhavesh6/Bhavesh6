- **Currently building** — [SafetyFirst](https://github.com/Bhavesh6/PPE-Detection), an RFID + YOLOv8 PPE access-control gate for work sites
- **Actually deployed** — a [five-room smart switch system](https://github.com/Bhavesh6/esp-rainmaker-smart-switches) running on hand-wired bare ESP32-WROOM-32E modules
- **Learning right now** — SigmaDSP audio design, CAN bus, and PCB work beyond the two-layer comfort zone
- **Ask me about** — ESP-NOW, non-blocking firmware, watchdogs, LiPo power paths, or why your relay flickers on boot
- **Fun fact** — my wall switches keep working with the Wi-Fi *and* the cloud completely down. Only the app needs internet.
- **1st place, hardware division** — CMR Hackfest 3.0 (national), plus 2nd runner-up overall

## Featured Projects

| Project | What it does | Tech |
|:--|:--|:--|
| **[SafetyFirst PPE Gate](https://github.com/Bhavesh6/PPE-Detection)** | RFID + YOLOv8 access-control gate. Checks hardhat, vest and mask against a policy an admin can change mid-shift. | `YOLOv8` `Python` `RPi` |
| **[Smart Switch System](https://github.com/Bhavesh6/esp-rainmaker-smart-switches)** | 5 rooms, 11 relays, bare WROOM-32E modules. Wall switches work with Wi-Fi and cloud fully down. | `ESP32` `RainMaker` |
| **[Smart Aquarium](https://github.com/Bhavesh6/Smart-Aquarium-ESP32)** | Offline-first feeding, pump cycling and 4 relays. Detects missed feeds on boot, watchdogs the cloud. | `ESP32` `SPIFFS` |
| **[ESP32 Race Robot](https://github.com/Bhavesh6/ESP32-RoboRace-bot)** | Tank drive on a two-board ESP-NOW link. 43A drivers, live current telemetry on the remote's OLED. | `ESP-NOW` `BTS7960` |
| **[SigmaDSP BT Speaker](https://github.com/Bhavesh6/SigmaDSP-Marshall-BT-Speaker)** | Portable speaker from raw chips, not a module. Live EQ over I²C, fully documented before soldering. | `ADAU1701` `LDAC` |
| **[RO Purifier Board](https://github.com/Bhavesh6/ESP32-Water-Purifier-Controller)** | Replaces the stock board. Sequenced pump/UV cycle, TDS monitoring, relays that default off. | `ESP32` `EEPROM` |
| **[PC Dock](https://github.com/Bhavesh6/pc-dock)** | Old Android phone as an always-on desk dock. CPU/GPU meters, media remote, macro pad. No cloud. | `Node` `PowerShell` |
| **[Portfolio](https://github.com/Bhavesh6/portfolio)** | No framework, no build step. The robot's face is a real port of `face.py` from my companion robot. | `HTML` `CSS` `JS` |
